Use Image Crawler with Atlas

Send the images you pick straight into your Atlas library on your Mac. It takes one command, once.

What you need

  • A Mac with the Atlas app
  • Image Crawler installed in Chrome, Dia, Arc, Brave, Edge or another Chromium browser

Set it up

  1. Open Atlas and make sure Settings ▸ MCP ▸ Atlas MCP is on.
  2. Open Terminal (in Applications ▸ Utilities), paste this command and press Return:
    curl -fsSL https://raw.githubusercontent.com/Push3in/Image-Crawler/main/atlas-bridge/get.sh | sh
    If your Mac asks to install developer tools (for Python), click Install, then run the command again.
  3. Close the Image Crawler gallery and open it again. Add to Atlas now appears when you select images.

Installed Image Crawler in another browser later? Run the same command again.

What the command does

It installs a small helper in ~/Library/Application Support/ImageCrawlerAtlas and tells your browsers that only Image Crawler may talk to it. When you click Add to Atlas, the extension hands the image addresses to the helper, and the helper asks Atlas to save them to your Inbox. Everything stays on your Mac. You can read the helper's code.

Remove it

curl -fsSL https://raw.githubusercontent.com/Push3in/Image-Crawler/main/atlas-bridge/get.sh | sh -s -- --uninstall

Not working?

  • Make sure Atlas is open and Atlas MCP is on, then run the setup command again.
  • Quit and reopen your browser.
  • The helper writes what happened to ~/Library/Logs/ImageCrawler-Atlas.log.
